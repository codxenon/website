---
title: Install a title update on Xenia
description: Install the required title update in Xenia Canary or Canary Netplay.
---

1. Find the required update in the [game compatibility table](/help/compatibility/). CoD Xe client ZIPs also include the updates in `title-updates/<game>/<TU>/`.
2. In Xenia, choose **Content → Install Content**, then select the title update file. Older builds may list **Install Content** in the **File** menu.
3. Wait for Xenia to confirm the installation, then launch the game again.
