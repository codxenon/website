title: Get help
description: Get setup help or report a problem with the CoD Xenon beta.
---

Join [CoD Xenon on Discord](https://discord.com/invite/wCgjAMEQU5) for setup help and beta feedback. For a reproducible project issue, use the relevant repository in the [CoD Xenon GitHub organisation](https://github.com/codxenon).

Include your platform, game, title update, game format (GOD, disc, or extracted), and CoD Xe revision. For map or mod issues, add the download name and revision, what you did, and what happened. A screenshot or the relevant Xenia log excerpt can help pinpoint the failure.
