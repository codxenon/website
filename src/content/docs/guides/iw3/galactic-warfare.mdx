## Install

Install Call of Duty 4 **TU4** and the [current CoD Xe client](/getting-started/). Close the game before copying the files.

1. Open the game content folder for your platform.

   | Platform | Game content folder                                     |
   | -------- | ------------------------------------------------------- |
   | Xbox 360 | `_codxe\games\iw3\` on your CoD Xe drive                |
   | Xenia    | `plugins\415607E6\_codxe\` in your Xenia storage folder |

2. Extract the ZIP there. It contains `mods/swm_gw1/` and eight folders under `usermaps/`. If you already play Galactic Warfare, keep your existing `mods/swm_gw1/scriptdata/` files when prompted. That folder holds editable bot names and waypoints.
3. Start multiplayer, open **Mods**, and load **Galactic Warfare**. Then choose a map under **Custom Maps**.

## Included maps

Anchorhead, Bestine, Bespin, Jundland, Jundland Dusk, Mos Eisley, Not a Cave, and Easybeat’s Rebellion. **Not a Cave** supports Deathmatch only.
