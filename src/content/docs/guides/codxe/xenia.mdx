Use [Xenia Canary or Canary Netplay](/guides/xenia/install/) and a clean copy of **Call of Duty 4** for Xbox 360 (USA / Europe). Run Xenia once to create its configuration, then close it.

## 1. Download the Xenia client

Extract the ZIP. It includes `patches`, `plugins` and `title-updates` at the top level.

## 2. Copy the patches and plugins

1. Put the supplied `patches` files in the patches directory for your Xenia build and the `plugins` folder in your Xenia storage directory. In a portable setup these folders sit beside the executable. Merge into the existing folders when updating.
2. Check that `plugins\415607E6\plugins.toml` and `plugins\415607E6\_codxe\modules\codxe.iw3.mp.xex` exist. Keep your own maps, mods and settings.
3. With Xenia closed, enable `allow_plugins` and `allow_game_relative_writes` in its configuration. [Xenia configuration guide](/guides/xenia/install/#configure-xenia-for-cod-xe).

## 3. Install TU4 and start multiplayer

Open Xenia and choose **File → Install Content…**. Select the file in `title-updates/iw3/TU4/` from the ZIP. After Xenia confirms installation, start Call of Duty 4 multiplayer and open **Mods**.

For this game, maps go in `plugins\415607E6\_codxe\usermaps\` and mods in `plugins\415607E6\_codxe\mods\`. [Browse maps](/games/iw3/maps/) or [choose a mod](/games/iw3/).
