You need an Xbox 360 that can load unsigned plugins, a clean extracted copy of **Call of Duty 4** (USA / Europe), and an HDD or USB drive.

## 1. Download the Xbox 360 client

Extract the ZIP on your computer. Keep the entire `_codxe` folder together.

## 2. Install TU4 and the client

1. Open `title-updates/iw3/TU4/` in the ZIP and copy the `TU_` file to the console’s HDD cache. [Xbox title update instructions](/guides/title-updates/xbox-360/).
2. Copy `_codxe` to the **root** of the drive you want to use. For example, the plugin on the first USB drive is `USB0:\_codxe\codxe.xex`. If updating, unload the plugin first, merge the new client files, and keep your existing maps, mods and settings.
3. Set a plugin slot in your loader to that exact `codxe.xex` path. In DashLaunch, save the configuration and restart the console.

## 3. Start multiplayer

Launch Call of Duty 4 multiplayer and open **Mods**. Custom maps go in `_codxe\games\iw3\usermaps\`; mods go in `_codxe\games\iw3\mods\` on the same drive.

[Browse maps](/games/iw3/maps/) or [choose a mod](/games/iw3/).
