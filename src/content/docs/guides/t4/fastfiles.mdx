## Install a map manually

Extract the ZIP into the game content folder below. The archive supplies `usermaps` and the map folder inside it.

| Platform | Game content folder                                                  |
| -------- | -------------------------------------------------------------------- |
| Xbox 360 | `_codxe\games\t4\` on the HDD or USB drive where CoD Xe is installed |
| Xenia    | `plugins\4156081C\_codxe\` in your Xenia storage directory           |

When updating manually, move the previous copy of that map out of `usermaps` before extracting the new version.

## What You Need

- A **genuine USA / Europe copy** of Call of Duty: World at War
- Call of Duty: World at War **TU7**
- The latest **CoD Xe** plugin

## Known Issues

- Missing sounds
- Low quality textures
- Pack-a-Punch on certain weapons on certain maps can crash the game
