CoD Xe guides require a complete, legally obtained copy of a supported Xbox
360 game. Prepare the game before installing CoD Xe, title updates, or mods.

<Aside type="caution" title="Use your own game copy">
  CoD Xenon does not provide game files and does not support piracy.
</Aside>

## Extract The Game Files

If your game is an ISO, extract its contents to a normal folder before
continuing. [**Xbox Image Browser**](https://consolemods.org/wiki/Xbox:ISO_Extraction_%26_Repacking#Xbox_Image_Browser)
is the recommended app, but any tool that correctly extracts Xbox 360 ISOs can
be used.

## Check The Game Folder

The current multiplayer guides use an extracted game folder. It should contain
the original game files, including `default_mp.xex`.

**Do not start with a folder that already contains unrelated patches or mods**.

## Match The Disc Version

Title updates are tied to a specific **Title ID** and **Media ID**. Check that
your game matches an entry in the supported games reference before continuing.
