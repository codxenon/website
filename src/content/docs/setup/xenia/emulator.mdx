Extract the emulator ZIP to its own folder. Run the emulator once and close it to create the configuration file. Look for `Storage root` in Xenia’s log if you need to find that folder.

## Configure Xenia for CoD Xe

Open the TOML config file for your installation. Its name varies by build, for example `xenia-canary.config.toml` or `xenia-canary-netplay.config.toml`. Edit the existing entries while Xenia is closed:

```toml
allow_plugins = true
allow_game_relative_writes = true
```

For keyboard input in the CoD Xe console, you can also set `keyboard_mode = 2`.
