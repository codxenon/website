---
title: Game formats
description: Launch your existing Xbox 360 game, including Games on Demand, with CoD Xe.
---

Use your own unmodified copy of a [supported game](/help/compatibility/). CoD Xe keeps its plugins, maps and mods in a separate folder, so **you can leave your game files as they are**.

| Game format           | Xbox 360                                          | Xenia Canary                                                                                                  |
| --------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Games on Demand (GOD) | Launch your installed copy from the dashboard.    | Keep the package file alongside its matching `.data` folder. Use **File → Open** and select the package file. |
| Disc or disc image    | Launch your disc as usual.                        | Use **File → Open** and select your Xbox 360 disc image.                                                      |
| Extracted game folder | Launch from your usual dashboard or file manager. | Use **File → Open** and select the game’s `.xex` file.                                                        |

To switch modes from a disc or GOD copy, use the game’s own menus. Check the [game compatibility table](/help/compatibility/) for the title update that matches your game build.

For help transferring a GOD copy to your PC, see [Xenia Canary's quickstart](https://github.com/xenia-canary/xenia-canary/wiki/Quickstart#section-3-importing-games-for-use-in-xenia).
