## Report A Problem

If you are familiar with GitHub, open the repository for the affected project
and create an issue there. The **Source Code** card at the end of each game
guide takes you to its repository.

Include the game, title update, platform, and a short description of what you
expected to happen and what happened instead. Screenshots or error messages can
help others reproduce the problem.
