## Install and play

1. Extract the map ZIP into your [World at War content folder](/setup/#game-content-folders). Each map goes in its own folder under `usermaps/`.
2. Start multiplayer and pick **Custom Maps** when setting up a System Link or private match.

See [Zombies maps](/games/t4/zombies/) for the co-op and solo collection.
