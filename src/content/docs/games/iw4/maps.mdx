Use the USA / Europe release of Modern Warfare 2 with **TU6** and [CoD Xe](/setup/) to play custom multiplayer maps.

## Install a map

Extract the map ZIP into your [Modern Warfare 2 content folder](/setup/#game-content-folders). Each map goes in its own folder under `usermaps/`.

If you’re updating a map, move its previous folder out of `usermaps/` before extracting the new ZIP.

## Use Custom Maps

When setting up a System Link or private match, open the map selector, choose **Custom Maps**, and select the map you installed.
